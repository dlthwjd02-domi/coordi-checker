내 맥에서 돌리기

코디 체커는 웹에서 설치 없이 바로 쓸 수 있어요. 이 페이지는 내 맥에 직접 설치해서 돌리고 싶을 때만 보면 됩니다.

직접 돌리면 상품 페이지를 내 맥이 직접 가져오고, 사진도 내 컴퓨터에만 저장됩니다.

웹에서 바로 쓰기 폴더 내려받기 (.zip) GitHub

쓰는 방법

  1. 폴더를 내려받아 압축을 풉니다 위의 “폴더 내려받기” 버튼을 누르면 coordi-checker-main.zip 이 저장돼요. 더블클릭해서 풀고, 원하는 위치(예: 서류 폴더)로 옮겨 두세요.
  2. start.command 를 더블클릭합니다 검은 터미널 창이 열리고 브라우저가 자동으로 뜹니다. 처음 한 번만 준비 작업으로 1~2분 걸려요. 그다음부터는 몇 초면 열립니다.
  3. 여행지 → 옷 순서로 넣습니다 나라나 도시를 한글로 검색하고 월을 고른 뒤, 상의·하의 상품 주소를 붙여넣고 “불러오기”를 누르면 됩니다.
“확인되지 않은 개발자” 경고가 뜨면
맥이 인터넷에서 받은 파일을 막는 거예요. start.command 를 우클릭(또는 control+클릭) → 열기 로 한 번만 실행하면 그다음부터는 더블클릭으로 됩니다.

끄고 다시 켜기

터미널 창을 닫거나 Ctrl+C 를 누르면 꺼집니다. 다시 켤 때도 start.command 더블클릭이에요. 이미 켜져 있으면 브라우저만 다시 엽니다.

여행지 기온에 맞는 옷차림

최근 3년 그 달의 실제 관측 기온을 가져와 8단계로 알려줍니다. 눈·비 오는 날수와 일교차까지 봐서 “실내가 더우니 벗을 수 있게 겹쳐 입으세요”, “신발은 예쁜 것보다 방수로” 같은 조언이 붙어요. 이번 달을 고르면 7일 실제 예보도 같이 나옵니다.

한글로 전 세계 어디든 검색됩니다 — 경주, 통영, 밴쿠버, 밴프, 치앙마이, 레이캬비크.

사진으로 넣기

웹 버전에서는 각 칸의 사진 버튼으로 상품 사진을 올릴 수 있어요. 올리면 배경을 자동으로 지웁니다 — 단색 배경은 바로, 휴대폰으로 찍은 사진은 사람 분리 모델로. 끌어다 놓기와 붙여넣기(스크린샷 찍어서 바로)도 됩니다.

색이 잘못 잡히면

  • 상품 카드의 “다른 색 N개” 로 원하는 컬러웨이를 고릅니다
  • 팔레트 칸을 클릭해 대표색을 바꿉니다
  • 그래도 안 되면 컬러 피커로 화면의 옷 색을 스포이드로 직접 찍으면 됩니다

알아둘 점

  • 유니클로·나이키·아임웹 쇼핑몰은 주소만 넣으면 잘 됩니다. 무신사·네이버 스마트스토어·쿠팡·에이블리는 주소로 안 됩니다 — 자동 수집을 막거나 화면을 앱에서 그리기 때문이에요. 이때는 상품 사진을 올리면 됩니다 (웹 버전의 “사진” 버튼).
  • 서버는 내 맥 안에서만 열려요. 같은 와이파이를 쓰는 다른 사람도 볼 수 없습니다.
  • 저장한 코디는 그 브라우저에만 남습니다. 다른 기기로는 안 넘어갑니다.
  • 기온 데이터는 Open-Meteo, 지역 검색은 Open-Meteo와 OpenStreetMap을 씁니다. 가입이나 키 발급은 필요 없어요.
